# Results

Put `ecerc_l2_results.zip` from the Colab run here. Unzipped, it contains `outputs/` with:

- `SUMMARY.md`: the verdict and key numbers
- `test_results.json`, `dev_selection.json`, `dev_diagnostics.json`
- `frozen_config.json`: every decision fixed before the test set was touched
- `checks.json`, `fidelity.json`, `data_gate.json`, `provenance.json`, `environment.json`, `run_log.jsonl`
- `tables/`: CSV tables
- `figures/`: plots
- `dumps/`: per-checkpoint log-probabilities
