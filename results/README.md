# Saved results

This folder keeps the minimum set of saved outputs an evaluator needs to check the numbers in [`../docs/report.md`](../docs/report.md). The files were copied unchanged from the Google Drive folders the notebooks wrote to. Per-run folders are not included: weights, prediction CSVs, per-epoch CSVs, training logs and per-run metrics files. See [Not included](#not-included).

## Layout

```
results/
├── stage0/                          Baseline verification (notebook 02)
│   ├── R0_ECERC_MODEL/
│   │   ├── config.json              settings and environment of the released-checkpoint evaluation
│   │   └── metrics.json             R0 validation and test metrics (per class, confusion matrix)
│   ├── orig_train_s0.log            upstream MELD/train.py, seed 0: one side of the B0 equivalence check
│   ├── baseline_sha256.txt          SHA-256 of the upstream MELD files and the checkpoint
│   └── summary_test/summary.md      test tables for R0 and B0 seed 0
└── stage2/                          Final experiment, 15 runs (notebook 03)
    ├── summary_valid/               validation summary
    └── summary_test/                test summary
```

Each Stage 2 summary folder holds:

| File | Content |
|---|---|
| `summary.md` | All tables, as printed in notebook 03 |
| `per_run.csv` | One row per run: selected epoch, accuracy, wF1, macro-F1, Fear and Disgust P/R/F1 |
| `per_variant.csv` | Mean ± std over seeds: accuracy, wF1, macro-F1, F1 of every class |
| `fear_disgust.csv` | Mean ± std P/R/F1 and mean TP/FP/FN for Fear and Disgust |
| `paired_vs_B0.csv` | Per-seed differences from B0: mean ± std, and the number of seeds above B0 |
| `confusion_<variant>.png` | Confusion matrix summed over the variant's 3 runs (counts, and % of each true class) |

Every summary file was written by [`MELD/analyze_imbalance.py`](../MELD/analyze_imbalance.py) `summary`. Each `summary.md` lists the `confusion_<variant>.csv` files that the analyzer also wrote. Those CSVs are left out here; the same matrices are in the PNGs.

Class index order everywhere: 0 Neutral, 1 Surprise, 2 Fear, 3 Sadness, 4 Joy, 5 Disgust, 6 Anger.

**Stage 1 (pilot).** No Stage 1 files are saved here. The pilot's summary folder and `stage1_record.txt` were not part of the exported results. The pilot results, the choice β = 0.999 and ρ = 2, and the record text are printed in notebook 02 (cells 35, 39 and 40).

**Equivalence check.** `orig_train_s0.log` is the upstream side of the check. The `compare` output, `RESULT: IDENTICAL. All 40 epochs match exactly.`, is printed in notebook 02 cell 24 and quoted in report §4.2.

**Figures.** [`../docs/figures/`](../docs/figures/) was generated by [`../scripts/make_figures.py`](../scripts/make_figures.py) from the 15 per-run `metrics.json` files, which are not stored here. The plotted per-run values are those in `stage2/summary_*/per_run.csv` (which rounds them to 2 decimals). The plotted means and paired differences are those in `per_variant.csv`, `fear_disgust.csv` and `paired_vs_B0.csv`.

## How the files were checked

These checks were run on the full raw export from Drive, before the per-run files were removed:

- **Against the notebooks.** For all 21 training runs, the final validation/test metrics and all 40 per-epoch lines printed in notebooks 02 and 03 match the saved run files. R0's `metrics.json` matches notebook 02 cell 16 and notebook 03 cell 15. It also matches the upstream `inference.py` output in notebook 01 cell 19: per-class F1, accuracy, weighted F1 and macro-F1.
- **Seed-0 repeats.** B0 seed 0 and the seed-0 CB0.999, FL2 and OS2 runs were each run twice, once in notebook 02 and once in notebook 03, in separate Colab sessions. For each pair, `metrics.json` and both prediction files are byte-identical, `epochs.csv` matches apart from wall-clock time, and `config.json` is identical.
- **Equivalence check.** Re-running `analyze_imbalance.py compare` on `orig_train_s0.log` and the saved B0 seed-0 run prints `RESULT: IDENTICAL`. The epoch lines of `orig_train_s0.log` match notebook 02 cell 22, ignoring the per-epoch time.
- **Summaries.** Re-running `analyze_imbalance.py summary` on the saved runs reproduces every CSV in these summary folders byte for byte, along with the tables in each `summary.md`. The same command on the five pilot runs reproduces notebook 02 cell 39 line for line.
- **Hashes.** `baseline_sha256.txt` matches the hashes printed in notebook 02 cells 5 and 14. `sha256sum -c` passes against this repository's `MELD/` files.

## Provenance of the Stage 0 files

The Drive folder `results/stage0/` holds two sets of Stage 0 outputs:

- **Top level**, uploaded on 4 October 2026 from an execution of the notebook 02 Stage 0 cells. The Stage 0 files here were copied from this set.
- **A nested `stage0/results/` folder**, created when notebook 02 cell 27 (`cp -R results …/stage0`) ran with `stage0/` already present. According to Drive's modification times, its files were written on 5 October 2026 by the session whose output is saved in notebook 02.

The nested copies were not exported, so they could not be compared byte for byte. The top-level copies match everything notebook 02 prints for the corresponding cells: metrics, all 40 epoch lines (ignoring wall-clock time) and the file hashes.

By Drive's listed sizes, the two sets agree for every R0 file, for the B0 seed-0 `config.json`, `metrics.json` and prediction files, and for `baseline_sha256.txt`. Only the three files that record wall-clock time differ, by 2 bytes each: B0's `epochs.csv` and `train.log`, and `orig_train_s0.log`.
